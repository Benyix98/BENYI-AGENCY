# 🚀 BENIA AGENCY - Landing Page Premium

Landing page de alta gama diseñada con estética **"Dark Luxury"**, optimizada para el sector Tech/IA.

## ✨ Características Premium
- **Modo Oscuro Profundo**: Paleta de colores Neon Green (#22C55E) y Chrome Black.
- **Interactividad 3D**: Flip cards interactivas para servicios con efectos de profundidad.
- **Glassmorphism**: Componentes con desenfoque de fondo y bordes brillantes.
- **Sistema de Partículas**: Fondo dinámico con partículas flotantes.
- **Responsive Design**: Totalmente adaptada desde monitores XL hasta dispositivos móviles.
- **Animaciones de Revelado**: Aparición fluida de contenido al hacer scroll.

## 📁 Estructura del Proyecto
- `index.html`: Estructura semántica y SEO optimizada.
- `styles.css`: Sistema de diseño moderno y animaciones CSS puras.
- `script.js`: Interacciones, sistema de partículas y animaciones de scroll.
- `PROMPTS.md`: Guía detallada para generar los assets visuales finales con IA.
- `images/`: Directorio para los assets visuales.

## 🚀 Visualización Local
Para ver el proyecto, simplemente abre el archivo `index.html` en cualquier navegador moderno.

También puedes usar un servidor local para una mejor experiencia de desarrollo:
```bash
npx serve .
```

## 🎨 Personalización de Imágenes
Debido al límite de cuota de generación de imágenes, se han incluido los prompts exactos en `PROMPTS.md`. Una vez generadas, guárdalas en la carpeta `images/` con los nombres indicados para que se integren automáticamente en el diseño.
